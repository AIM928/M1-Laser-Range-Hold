# M1 Laser Range Hold v0.1.2

GHPC M1/M1IP mod: invalid smoke or dust returns blink `0000`; the last valid ballistic range is retained.

Install: exit GHPC and copy `Mods/M1LaserRangeHold.dll` beside the game's other Mods. Requires MelonLoader; reference version 0.7.3, GHPC 20261014. No vehicle mod required.

Known limitation: failed ranging does not re-engage lead tracking. Dust detection is approximate.

Download the release ZIP, not the automatic source archive.
